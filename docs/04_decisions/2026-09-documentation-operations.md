# 決定記録: ドキュメント運用の統一

- 日付: 2026-09-02
- ステータス: 決定

## 背景

仕様、タスク、AI ツール固有の指示が `.agent/`、`.gemini/`、`.github/` に分散していた。旧 `docs` submodule 設定も残っており、現行の正本が判別しにくかった。

## 決定

リポジトリ直下の `docs/` を、企画・要件・仕様・意思決定・実行資料の正本とする。共通の作業ルールは `AGENTS.md` に集約し、`CLAUDE.md` は `AGENTS.md` を参照する。

## 理由

資料の種類ごとの置き場所を固定し、コード変更とドキュメント更新を同じ作業に含めやすくするため。

## 採用しなかった案

- ツールごとの指示ファイルをそれぞれ維持する。
- 旧資料を削除する。
- 外部 submodule を docs の正本として維持する。

## 影響と次の作業

旧資料は `99_archive/2026-09-legacy-agent-workspace/` に保存する。現行で必要な内容は検証のうえ番号付きディレクトリへ再編する。
