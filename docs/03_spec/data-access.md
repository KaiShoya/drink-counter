# データアクセスとエラー処理

ステータス: 旧通信仕様からサルベージ。実装変更前に Repository と Store の実コードを確認する。

## ルール

- Supabase SDK の呼び出しは `app/repositories/` に集約する。
- Data Store は Repository を呼び、UI 通知を行わずにエラーを上位へ渡す。
- Page Store は複数の Data Store を統合し、ローディング状態、利用者向け通知、ログ記録を管理する。
- コンポーネントは Page Store のアクションを使い、直接のデータアクセスを避ける。
- 利用者へのメッセージは i18n キーで管理し、UI に直接埋め込まない。

## ネットワーク方針

自動リトライと Repository 内キャッシュは既定で導入しない。タイムアウト、リトライ、オフライン書き込みの要否は、対象操作の冪等性と利用者への影響を確認してから決定記録に残す。

オフライン対応は T-0034 として未決定である。
