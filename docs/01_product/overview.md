# drink-counter 概要

## 目的

drink-counter は、飲んだ杯数を家計簿のように毎日記録し、飲み過ぎを防止するための Web アプリです。

飲酒量を記憶や感覚だけに頼らず、日ごとの記録と集計で可視化することで、自分の飲酒ペースを把握し、必要に応じて量や頻度を見直せるようにします。

## 利用者と利用場面

飲酒量を自分で管理したい人が、飲んだ直後または一日の終わりに、その日の杯数を記録します。月・年・全期間の記録を振り返り、飲み過ぎていないか、飲酒ペースが目標から外れていないかを確認します。

## 提供する価値

- **手軽な記録**: 飲み物ごとに杯数をすばやく増減し、毎日の記録を続けやすくする。
- **見える化**: 日別・月別・年別・全期間の集計から、飲酒量と頻度の傾向を把握できる。
- **予防**: 日々の記録と目標ペースを手がかりに、飲み過ぎに早く気づき、行動を見直せる。
- **自分に合う管理**: 飲み物、分類、日付切替時刻、タイムゾーンを利用者の生活に合わせて設定できる。

## 成功の目安

- 利用者が、その日に飲んだ杯数を迷わず記録できる。
- 利用者が、一定期間の飲酒量・頻度を振り返れる。
- 利用者が、記録から自分の飲酒ペースを認識し、飲み過ぎの予防に役立てられる。

## 主要な用語

- 飲み物: 記録対象となる飲料。
- ラベル: 飲み物を整理する分類。
- カウント: 指定日付に対する飲み物の杯数記録。
- 目標ペース: 飲み過ぎの予防を支援するため、記録と比較する利用者ごとの目安。
