# 中核要件: 飲酒量の記録と飲み過ぎの予防

ステータス: 現行プロダクト方針（2026-09-02）

## プロダクト要件

drink-counter は、利用者が自分の飲んだ杯数を家計簿のように記録し、飲酒量と頻度を把握して飲み過ぎを防止できることを最優先とする。

## 機能要件

### 記録

- 利用者は、飲み物ごとに指定日の杯数を記録、増加、減少できる。
- 利用者は、記録対象の飲み物を追加、編集、整理できる。
- 日付の扱いは利用者のタイムゾーンと日付切替時刻に従う。
- 記録操作は、日常的に継続できる少ない手順で完了する。

### 振り返り

- 利用者は、日々の記録を月次・年次・全期間で確認できる。
- 集計では、飲酒量と頻度の傾向を把握できる。
- 記録が不足している場合でも、誤解を招かない状態表示を行う。

### 飲み過ぎの予防

- 利用者は、自分の飲酒ペースを確認できる。
- 目標や目安を設定・表示する機能を追加・変更する場合は、過度な断定や医療的な判断を行わず、自己管理を支援する表現にする。
- 予防に関わる表示は、記録を責めるものではなく、利用者が次の行動を選べる情報として提供する。

## 非機能要件

- 日々の主要な記録操作は、スマートフォン幅でも利用しやすいこと。
- 利用者の記録は他の利用者から分離されること。
- 記録・集計・設定の変更でデータ整合性を失わないこと。
- 利用者向け文言は日本語・英語で一貫して扱えること。

## 受け入れ基準

- 利用者が一日の飲酒記録を追加・訂正し、結果を確認できる。
- 利用者が月次または年次の集計から飲酒傾向を確認できる。
- 利用者が飲酒ペースを振り返るための情報に到達できる。
- 記録がない、または少ない期間でも画面が壊れず、状態が理解できる。
